解决的核心痛点

即使拥有大量数据源，分析师依然耗费 70% 以上的时间在机械性搜集与整理上，而非真正的洞察。

信息碎片化

新闻、社交媒体、财报、研报分散于数十个平台，人工切换效率极低，关键信息极易遗漏。

分析浅层化

缺乏长链推理与跨源关联能力，单条信息易被误读，弱信号难以捕捉，深层风险被淹没在噪音中。

预警滞后

传统日报/周报模式以天为单位，等报告到达决策层时，市场窗口早已关闭。

系统架构

分层多 Agent 架构，基于 LangGraph 编排复杂逻辑流，实现"感知—理解—推理—行动"全闭环。

抓取 Agent

基于 Playwright 与亮数据代理池，自主解析目标页面并应对反爬。新闻、社交媒体、财报、研报等异构数据实时注入 Kafka 管道。

🧹

清洗 Agent

结构化抽取模型将非结构化文本转为统一 Schema，完成去重与实体对齐，确保下游分析的数据质量。

🧠

分析 Agent（核心）

思维链引擎：调用行业知识图谱与 RAG 检索补充背景，通过"假设—验证—修正"多轮推理进行舆情情感、竞争态势、供应链风险深度解析，识别弱信号关联。

🚨

汇总与预警 Agent

多维度发现整合为带置信度评分的结构化报告，通过企业微信自动推送；触发阈值时直接生成行动建议。

多 Agent 辩论机制

对抗式协作显著减少单一模型幻觉带来的误判，提升分析可靠性。
